# 地下管线透视与开挖防护系统

浏览器端三维地下管线透视、开挖方案设计与挖机作业防破坏预警系统。
TypeScript + three.js（WebGL2），管线数据 / 开挖方案 / 姿态录制持久化在 IndexedDB。

## 运行

```bash
npm install
npm run dev        # 开发服务器
npm run build      # 类型检查 + 生产构建
npm run test:geo   # 几何精度验证（报警距离 ≤1cm 等 14 项）
```

首次使用：进入「管线数据」页，点 **生成测试数据并导入**（一个十字路口 + 两条支路，
228 段管线，含上下交叉；掺有缺埋深、坐标重复、精度等级未填、引用不存在管点的坏数据，
导入报告会逐条列出）。也可点「下载测试CSV」查看格式后导入自己的普查成果表。

## 页面

| 页面 | 功能 |
| --- | --- |
| 管线数据 | 管点表/管段表 CSV 导入；缺埋深按相邻管点插值并标「推测」；坐标重复、悬空管点引用等坏行报告 |
| 道路地层 | 路面结构层/杂填土/粉质黏土/砂层分层透明度调节，透视下看 |
| 透视浏览 | 六类管线按行业色标显隐；任意两点画剖切线生成横断面图，净距按 GB 50289 简化值检查、违规标红 |
| 开挖方案 | 地面绘制坑底轮廓，设深度与放坡比；基坑从地层中真实挖除（着色器裁剪），坑壁上直接标注出露管线与埋深 |
| 挖机作业 | 动臂/斗杆/铲斗三关节滑块+键盘（Q/A、W/S、E/D、方向键）控制；齿尖到最近管线包络距离实时显示；燃气/电力 1m 黄警、0.5m 红警并弹窗；姿态可录制回放 |
| 施工交底 | 开挖影响区（含 1m 缓冲）管线清单、权属单位、必须人工探挖段落；平面图+横断面图，一键导出 HTML 交底文件 |

## 关键设计

**报警精度（≤1cm）**——解析距离是唯一权威数据源：
`src/geo.ts` 的点到线段距离 → `src/envelope.ts` 减去（管外半径 + 不确定度半径）。
渲染侧包络网格与着色器使用同一组胶囊参数（中心线 A/B、包络半径），
可见包络面即解析包络面。`test/geo.test.ts` 用点到三角形距离对渲染网格做了
300 个随机点位的实测比对，偏差 < 1cm。

**不确定包络**：开挖实测 ±0.05m 最窄，电磁法 ±0.25m，探地雷达 ±0.30m，
缺埋深插值/缺精度等级一律按推测 ±0.50m 最宽。包络在片元着色器里按胶囊体
有向距离场做边缘渐隐（`src/materials.ts` 的 `sdCapsule`）。

**顺序无关透明（OIT）**：地层、路面、包络全部走加权混合 OIT
（`src/oit.ts`）。WebGL2 不支持逐附件混合，故用两遍法——累积 pass（ONE,ONE）
+ 透过率 pass（ZERO,1−SRC）共享不透明深度，最后全屏合成。
透明物体渲染顺序任意、结果一致，几百段管线叠在透明地层里转动视角不会闪烁错乱。

**基坑开挖体**：坑底多边形 + 放坡比定义开挖体，地层片元在着色器里做
开挖体包含测试直接 discard（`inExcavation`），坑壁出露管线由
线段-坡面解析求交（`segPitWallIntersections`）定位并打标签。

## 数据格式

管点表 CSV：`点号,X,Y,地面高程,管点类型,附属物`
管段表 CSV：`段号,起点号,终点号,管线类别,管径mm,材质,起点埋深,终点埋深,探测方法,精度等级,权属单位,断面,参数A,参数B`

- 管线类别：给水/排水/燃气/电力/通信/热力；管点类型：检查井/阀门/三通/变径/一般点
- 断面：圆管 / 排管（参数A=行数,参数B=列数）/ 方沟（参数A=宽m,参数B=高m）
- 探测方法：开挖实测/电磁法/探地雷达/推测；精度等级：A/B/C（缺填按推测加宽包络）

# 地下管线透视与开挖防护系统

浏览器端三维地下管线透视、开挖仿真与挖机作业防碰撞系统。TypeScript + three.js + IndexedDB,纯前端、无需后端。

## 启动

```bash
npm install
npm run dev        # 开发服务器
npm run build      # 类型检查 + 生产构建
npm run preview    # 预览构建产物
```

## 两项关键质量指标的实现与验证

### 1. 报警距离精度 ≤ 1cm

齿尖到管线**不确定包络外表面**的权威距离用解析胶囊 SDF:

```
dist = pointToSegment(tooth, a, b) - envelopeRadius
```

`挖机作业` 页内置自检:对 24 段代表性管线、在包络内外多方向布点,把解析结果与
**包络网格三角形暴力最近距离**(Ericson 点-三角形算法)逐点对照。当前最大误差
**1.24 mm(≤10 mm 通过)**。

> 调试中发现并修复了一个真实几何 bug:胶囊端盖误用了完整球体,内半球面片穿入
> 圆柱内部,在接缝区形成比真实表面更近的虚假面,导致暴力距离偏差 16mm。
> 修复为仅生成朝外半球(`phiLength = π/2`),网格外表面与解析 SDF 完全一致。

报警分级仅对**燃气、电力**生效:距离 ≤1.0m 黄灯、≤0.5m 红灯并弹横幅;其他行业
只显示距离不报警。端到端实测电力管:0.12m→红、0.65m→黄、1.61m→无报警。

### 2. 顺序无关透明(OIT)无闪烁错乱

路面、三层地层、几十上百个不确定包络均为半透明物体。采用**两遍加权混合 OIT**
(Weighted Blended OIT, McGuire & Bavoil 2013):

- pass 1 写累加缓冲(`vec4` 半浮点):权重颜色与 alpha 分别加权求和;
- pass 2 写 revealage 缓冲(单字节):记录透过率;
- 合成 pass:`color = accum.rgb/accum.a * reveal + bg * (1-reveal)`。

所有透明片元在两遍里各自独立累加,**与绘制顺序完全无关**,转视角时不闪烁、
不出现前后错乱。深度纹理在两遍间共享,保证不透明管线正确遮挡透明地层。

## 数据模型

- 六行业按 CJJ/T 7 风格色标:给水蓝、排水棕、燃气黄、电力红、通信紫、热力橙。
- 管点:检查井(井筒+井室)、阀门、三通、变径;管段:圆管、电力/通信排管(按孔数断面排列)、方沟(宽高)。
- 每段带起止埋深、管径、材质、探测方法、精度等级。
- 不确定包络半径 = 探测方法基础误差 × 精度系数 ×(推测段 1.5 倍):开挖实测最窄,电磁/雷达居中,推测最宽。
- CSV 导入:缺埋深按同行业相邻管点距离倒数加权插值并标记推测;坐标重复、悬空管段(连接不存在管点)、精度缺失等坏行逐条报错,错误行剔除。

## 测试数据

`src/data/generator.ts` 生成十字路口(东西+南北主干道)+ 两条支路的确定性数据集:
**227 个管点、203 段管段**,含上下层交叉、电力排管、排水方沟、燃气 A 级实测段;
并注入缺埋深、坐标重复、两条悬空管段、精度等级缺失、孤立推测链等坏数据。
首次启动自动生成并写入 IndexedDB,校验结果一并持久化,刷新后坏数据报告仍在。
